# Upstream Class Mapping

The upstream source for `miku-text-bundle` has not been fixed yet.

When the upstream source is selected, record mappings in this shape:

```text
upstream file:
  <upstream-root>/src/<target>

java classes:
  jp.igapyon.mikutextbundle.<package>.<ClassName>

notes:
  - facade:
  - helper split:
  - Java-side extension:
```
