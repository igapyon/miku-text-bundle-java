# Release Notes: v1.2.0

`v1.2.0` follows upstream `miku-text-bundle` `v1.2.0` and improves Part readability and preview operation.

## Changes

- Added `--dry-run` to estimate collection and generated Part counts without writing output files.
- Added `CliOptions.dryRun` and `BundleResult.dryRun` to the Java core API.
- Added horizontal rules before the second and later file chunks in each Part Markdown file.
- Updated the project and CLI version to `1.2.0` as part of the upstream-following step.

## Verification

- Covered by the final `v1.3.0` maintenance verification.
